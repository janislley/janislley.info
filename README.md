# janislley.info

Personal website of Janislley Oliveira, built with plain HTML, CSS, and JavaScript.

## Pages

- About me (`index.html`)
- CV (`cv.html`)
- Research (`research.html`)
- Publications (`publications.html`)
- Presentations (`presentations.html`)
- Teaching (`teaching.html`)
- Contact (`contact.html`)

## Local preview

Open `index.html` in a browser.

## Deployment

The site is deployed to GitHub Pages by the workflow in
`.github/workflows/pages.yml` whenever changes are pushed to the `main` branch.
The custom domain is `janislley.info`.
